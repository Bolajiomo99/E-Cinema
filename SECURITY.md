# Security

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately instead:

- On GitHub: the **Security** tab of this repository, then **Report a vulnerability**.
- By email: admin@e-cinema.net, with "Security" in the subject.

Tell us what you found, how to reproduce it, and what someone could do with it. We reply within 3 working days and keep you updated until it is fixed.

## Scope

- The live site, https://e-cinema.net, and its API.
- The code in this repository.

Please test only with your own accounts and PayPal sandbox payments. Don't access other people's data, run denial-of-service tests, or send spam.

## Supported versions

Only the current `main` branch, which is what runs on e-cinema.net, gets security fixes.
